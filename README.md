# 망상 일본행

인천에서 떠나는 70~80만 원짜리 일본 여행 망상 사이트.
가고 싶은 여행을 고르면 항공권·숙소 검색 링크, 하루하루 일정, 총 예상 경비가 나옵니다.

## 지금 들어있는 여행

| 여행 | 컨셉 | 3박 4일 예상 (짠내·게스트하우스) |
| --- | --- | --- |
| 도쿄 | 아키하바라, 애니 성지 순례, 시로바코 마츠테이 | 약 70만 원 |
| 후쿠오카 | 다자이후, 가마도 신사, 후쓰카이치 온천, 야나기가와 | 약 52만 원 |
| 오사카·나라·교토 | 고즈넉한 옛 도시 산책 | 약 59만 원 |

가격은 비수기 평일 기준 대략값입니다. 실제 가격은 사이트의 검색 버튼으로 확인하세요.

## 기능

- 출발일, 기간(2박/3박), 숙소 등급, 식비 모드, 쇼핑 예산, 환율을 바꾸면 경비가 바로 다시 계산됨
- 목표·최대 예산 대비 "예산 안 / 빠듯 / 초과" 도장 표시
- 성수기(연말연시, 설·추석, 일본 골든위크, 여름)와 금·토 출발이면 항공권 가격을 올려서 계산
- 날짜가 채워진 스카이스캐너·네이버 항공권·구글 항공편·부킹닷컴 검색 링크
- 일자별 일정표와 장소별 교통비·입장료
- 실제 항공권 가격 반영: 구글 항공권 가격 알림 메일, Aviasales 최근 검색가, 구글 항공편(SerpApi) 중 연결한 것
- 구글 가격 그래프·구글 탐색(지도) 바로가기
- 최저가 레이더: 여행지별로 가장 싼 출발일 5개, 누르면 그 날짜로 바로 계산
- 땡처리·특가 사이트 모음 (가격 비교, 땡처리, 저가항공 공식 특가)
- 쉬는 날 경고 (예: 마츠테이는 일요일 휴무로 알려져 있어서, 그날이 일요일이면 빨간 경고)
- 망상 메모장 (브라우저에 저장)

## 구글 항공권 가격 알림 연결하기 (API 키 없이)

구글 항공권의 "가격 추적" 알림 메일을 구글 시트로 모으고, 사이트가 그 가격을 쓰게 하는 방법이에요.
구글이 내 지메일로 보내준 가격을 그대로 쓰는 거라 API 키가 필요 없어요.

```
구글 항공권 가격 추적 → 지메일 알림 → Apps Script가 1시간마다 시트에 정리
→ 웹 앱 주소 → GitHub Actions가 하루 두 번 읽음 → data/prices.json → 사이트
```

1. **가격 추적 켜기**: 사이트의 "구글 항공편" 버튼으로 검색을 열고, 결과 위의 "가격 추적"을 켜요.
   가고 싶은 여행지·날짜마다 하나씩 켜두면 돼요.
2. **시트 만들기**: 구글 드라이브에서 새 구글 시트를 만들어요. 이름은 아무거나.
3. **스크립트 넣기**: 시트 메뉴 확장 프로그램 → Apps Script → 기본 코드를 지우고
   이 저장소의 `google-apps-script/Code.gs` 내용을 통째로 붙여넣고 저장.
4. **처음 실행**: 위쪽 함수 선택에서 `setup` 을 고르고 실행 → 권한 허용.
   지메일 읽기와 시트 쓰기 권한을 물어봐요. "확인되지 않은 앱" 경고가 나오면 고급 → 이동을 누르면 돼요.
   내가 만든 스크립트라 그래요. 이후엔 1시간마다 알아서 돌아요.
5. **웹 앱 배포**: 배포 → 새 배포 → 유형 "웹 앱", 실행 사용자 "나", 액세스 권한 "모든 사용자" → 배포 → 웹 앱 URL 복사.
   이 주소는 도시, 가격, 여행 날짜만 내보내요. 메일 내용이나 이메일 주소는 안 나가요.
6. **GitHub에 주소 넣기**: 저장소 Settings → Secrets and variables → Actions → New repository secret,
   이름 `GOOGLE_ALERTS_URL`, 값은 복사한 웹 앱 URL.
7. Actions 탭 → "항공권 가격 갱신" → Run workflow 로 한 번 실행.

시트의 "알림" 탭에 줄이 쌓이는데 가격 칸이 비어 있으면, 구글 메일 형식을 스크립트가 못 읽은 거예요.
그 메일 내용을 알려주면 `parseAlert_` 를 맞춰 고치면 돼요. 알림 메일이 아예 안 잡히면 `GMAIL_QUERY` 의
보낸 사람 주소를 실제 메일의 주소로 바꿔주세요.

## 실시간 가격 연결하기 (API)

사이트는 정적 파일이라 API 키를 화면 코드에 넣으면 누구나 볼 수 있어요. 그래서 키는 GitHub에만 넣고,
GitHub Actions가 매일 오전·오후 6시 17분(한국 시간)에 가격을 가져와 `data/prices.json`을 갱신합니다.
사이트는 그 파일을 읽어요. 키가 없으면 추정 가격으로 그대로 동작합니다.

| 출처 | 무엇을 주나 | 비용 | 필요한 키 |
| --- | --- | --- | --- |
| Travelpayouts (Aviasales 데이터 API) | 최근 2~7일 사이 실제로 검색된 가격 중 날짜별 최저가. 앞으로 4달, 2박·3박 일정 | 무료 (가입 필요) | `TRAVELPAYOUTS_TOKEN` |
| SerpApi 구글 항공편 | 여행지마다 가장 싼 날짜를 구글 항공편으로 다시 확인 + 구글이 판단한 가격 수준(낮음/보통/높음) | 무료 250회/월, 하루 3회 사용 | `SERPAPI_KEY` |

둘 중 하나만 넣어도 됩니다. 추천은 Travelpayouts부터.

1. travelpayouts.com 에 가입하고 Aviasales 프로그램에 참여한 뒤, 프로필의 API token을 복사
2. (선택) serpapi.com 에 가입하고 API key를 복사
3. 이 저장소의 Settings → Secrets and variables → Actions → New repository secret 에서
   `TRAVELPAYOUTS_TOKEN`, `SERPAPI_KEY` 라는 이름으로 저장
4. Actions 탭 → "항공권 가격 갱신" → Run workflow 로 한 번 바로 실행

주의: 예약 실행(schedule)은 기본 브랜치(main)에 있는 워크플로만 돌아가요. 이 작업이 main에 합쳐진 뒤부터 매일 실행됩니다.

참고로 Amadeus의 개인용(Self-Service) 항공 API는 2026년 7월에 종료돼서 쓰지 않았고,
스카이스캐너·구글 항공편은 개인에게 공식 API를 열어주지 않아요. 구글 항공편 가격은 SerpApi를 통해 가져옵니다.

## 구조

```
index.html       화면 뼈대
css/styles.css   디자인
js/data.js       여행 데이터 (지역, 가격, 일정). 새 여행은 여기에 추가
js/app.js        경비 계산과 화면 그리기
data/prices.json 실제 항공권 가격 (자동 갱신, 직접 고치지 않기)
scripts/fetch-prices.mjs        가격 가져오는 스크립트
google-apps-script/Code.gs      지메일 가격 알림 → 구글 시트 → 웹 앱 (구글 Apps Script에 붙여넣어 사용)
.github/workflows/prices.yml    매일 가격 갱신 예약
```

빌드 과정이 없는 순수 HTML/CSS/JavaScript입니다. `index.html`을 브라우저로 열면 바로 동작합니다.
파일을 직접 열면 브라우저가 `data/prices.json`을 못 읽어서 추정 가격만 보여요. 실제 가격까지 보려면
`python3 -m http.server` 로 띄우거나 GitHub Pages 주소로 보세요.

## 새 여행 추가하기

`js/data.js`의 `destinations` 배열에 기존 항목과 같은 모양의 객체를 하나 추가하면 카드가 생깁니다.
카드 색은 `css/styles.css`에서 `--tokyo` 같은 색 토큰과 `.ticket[data-id="..."]` 규칙을 하나 추가하면 됩니다.

## 공개하기 (GitHub Pages)

저장소 Settings → Pages → Source를 "Deploy from a branch", 브랜치를 선택하고 폴더를 `/ (root)`로 두면
`https://<사용자명>.github.io/JapanTrip/` 주소로 공개됩니다.
